# Copay

- `frontend/` — Expo (React Native) app. See `frontend/README.md`.
- `backend/` — Hono API on Node.js. See `backend/README.md`.

Each is a separate project with its own `package.json`; install and run them independently:

```bash
cd frontend && npm install && npx expo start
cd backend && npm install && npm run dev
```
